# 📚 Carpeta de Archivos PDF para Lectura Virtual

En esta carpeta se alojan los documentos **PDF** de los libros físicos de la biblioteca 3D. 

Cualquier archivo PDF colocado aquí (o en la carpeta `ebooks/`) será detectado automáticamente por el servidor de la biblioteca y habilitará la lectura virtual en 3D.

---

## 📌 Guía Rápida de Uso

1. **Nombre por ISBN (Recomendado)**:
   - Nombra tu archivo con el código ISBN de 13 dígitos seguido de `.pdf`.
   - Ejemplo: `9788467550030.pdf`

2. **Nombre por Título**:
   - También puedes nombrarlo con el título exacto o similar al libro.
   - Ejemplo: `Donde los arboles cantan.pdf`
